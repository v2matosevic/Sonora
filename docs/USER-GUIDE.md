# Use Sonora

Sonora

Open songs or add a folder, then choose a track in Up next. Play/pause, previous/next, seeking,
shuffle and repeat are in the transport. Crossfade starts off: click its control or press C and
choose a duration. The choice is remembered. Playback details show the actual source and output.
Space toggles playback, Ctrl+Left/Right skips tracks, F1 shows shortcuts. Focused controls/text
fields own their keys. Native media keys use the app's Windows session; physical routing can vary.


F1 lists shortcuts. Light/dark/follow-Windows themes are in More.
